## 🧠 Engineering Principles

I believe good software engineering is built around a few fundamental principles:

- Understand the problem before writing code.
- Prefer simple solutions over unnecessary complexity.
- Design for maintainability and evolution.
- Treat accessibility and performance as engineering requirements.
- Automate repetitive and error-prone processes.
- Make code easy to test and reason about.
- Use architecture to enable change, not prevent it.
- Keep technical decisions aligned with product requirements.
- Use AI to augment engineering capabilities, not replace engineering judgment.
- Continuously learn across technologies, platforms, and disciplines.

# 🚀 Selected Projects

## DiaBem — Web / PWA

DiaBem is a **Progressive Web App (PWA)** for personal diabetes tracking, designed with a mobile-first experience, local encrypted storage, and offline capabilities.

The application allows users to record glucose measurements, meals, physical activities, medications, and personal observations while providing a timeline for tracking patterns, evolution, and statistics over time.

The project represents my approach to building a complete product-oriented web application, combining frontend architecture, mobile-first UX, local persistence, offline capabilities, and privacy-oriented data handling.

**Stack:** Next.js, TypeScript, PWA, local storage, responsive design

**Repository:** [github.com/ruanvalente/diabem](https://github.com/ruanvalente/diabem)

> **Important:** DiaBem is a tool for organizing and tracking personal data. It does not provide medical diagnosis and does not replace guidance from healthcare professionals.
